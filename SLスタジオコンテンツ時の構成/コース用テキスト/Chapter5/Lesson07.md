# Lesson07：【課題】差分確認と実装結果の整理

## 課題の概要

Lesson05で実装したダッシュボードのコードに対して、差分確認と整理を行ってください。

---

## 課題1：差分確認

VSCodeのソース管理タブを開き、以下の観点で全ての変更ファイルを確認してください。

### チェック項目

- [ ] 不要な `console.log` が残っていないか
- [ ] コメントアウトした不要なコードが残っていないか
- [ ] 未使用の `import` 文が残っていないか
- [ ] インデントやフォーマットが崩れていないか
- [ ] 意図しないファイルの変更が含まれていないか

---

## 課題2：不要コードの修正

差分確認で問題のあるコードを見つけた場合は、修正してください。

修正後、再度差分を確認し、修正内容が正しいことをチェックしましょう。

---

## 課題3：最終コミットとプッシュ

整理が完了したら、コミットしてリモートリポジトリにプッシュしてください。

```bash
git add .
git commit -m "ダッシュボードの実装完了・コード整理済み"
git push origin main
```

## 振り返り

このChapterで実践した開発プロセスの全体像を振り返りましょう。

```
① コードリーディング（Lesson01）
      ↓
② 実装計画の作成（Lesson02〜03）
      ↓
③ 実装（Lesson04〜05）
      ↓
④ 差分確認・整理（Lesson06〜07）
      ↓
⑤ コミット・プッシュ
```

この **段取り → 実装 → 確認 → 整理** のサイクルは、次のChapter以降でも繰り返し実践します。

- 開発プロセスの全サイクル（コードリーディング → 段取り → 実装 → 整理）を体験した
