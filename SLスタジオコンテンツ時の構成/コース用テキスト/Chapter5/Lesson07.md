# Lesson07：【課題】差分確認と実装結果の整理

## 課題の概要

Lesson05で実装したダッシュボードのコードに対して、差分確認と整理を行ってください。

---

## 課題1：差分確認

### 課題設問

VSCodeのソース管理タブ（`Ctrl + Shift + G`）を開き、全ての変更ファイルを確認してください。以下の各チェック項目について、該当する問題箇所があったかどうかを回答してください。

1. 不要な `console.log` が残っていないか
2. コメントアウトした不要なコードが残っていないか
3. 未使用の `import` 文が残っていないか
4. インデントやフォーマットが崩れていないか
5. 意図しないファイルの変更が含まれていないか

### 解答

1. 開発中に入れたデバッグ用の `console.log` は全て削除する。エラーハンドリングの `console.error` は残してよい。
2. 試行錯誤の過程でコメントアウトした `// const oldChart = ...` のようなコードは削除する。説明のためのコメントは残す。
3. 途中で使わなくなったコンポーネントや関数の `import` 文は削除する。例：`PlaceholderChart` を削除した後にimport文が残っている場合。
4. ファイル内のインデントが2スペースまたは4スペースで統一されていることを確認する。
5. 変更予定のないファイル（例：`node_modules` 配下や設定ファイル）が変更されていないこと。`.gitignore` に `node_modules` が含まれていることも確認する。

---

## 課題2：不要コードの修正

### 課題設問

課題1で問題のあるコードを見つけた場合は修正してください。修正後、再度ソース管理タブで差分を確認し、修正内容が正しいことをチェックしてください。

修正した箇所があれば記録してください（修正がなかった場合は「なし」と記載）。

### 解答

修正例：
- `Dashboard.tsx` から `import PlaceholderChart from ...` の行を削除した
- `SalesChart.tsx` から `console.log('data:', data)` を削除した
- `App.tsx` のインデントを2スペースに統一した

修正がなかった場合は「差分確認の結果、修正すべき箇所はなし」と記載する。

---

## 課題3：最終コミットとプッシュ

### 課題設問

整理が完了したら、コミットしてリモートリポジトリにプッシュしてください。コミットメッセージは実施した内容が分かるものにすること。

### 解答

```bash
git add .
git commit -m "ダッシュボードの実装完了・コード整理済み"
git push origin main
```

## 課題4：開発プロセスの振り返り

### 課題設問

このChapterで実践した開発プロセスの全体像を、以下の空欄を埋めて完成させてください。

```
① ___________（Lesson01）
      ↓
② ___________（Lesson02〜03）
      ↓
③ ___________（Lesson04〜05）
      ↓
④ ___________（Lesson06〜07）
      ↓

```

### 解答

```
      ↓

      ↓

```
