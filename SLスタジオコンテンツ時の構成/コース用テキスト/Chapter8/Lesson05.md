# Lesson05：【実践課題】機能の結合と動作テスト・整理

## 課題の概要

Chapter7〜8で実装した全機能（新規登録・編集・一覧・詳細・削除）を統合し、**一連の操作が正常に動作することをテスト**してください。

---

## 課題1：全機能の統合テスト

### 課題設問

以下の操作を順番に実施し、各操作後の結果を記録してください。

| 手順 | 操作 | 確認すること |
|---|---|---|
| 1 | `/users` にアクセス | ユーザー一覧がカード形式で表示されるか |
| 2 | 新しいユーザーを登録 | 一覧に新ユーザーが追加表示されるか |
| 3 | 登録したユーザーの「詳細」をクリック | 詳細画面に正しい情報が表示されるか |
| 4 | 「編集」からユーザー情報を変更 | 一覧で変更が反映されているか |
| 5 | 「削除」→ モーダルで確認 → 実行 | 一覧からユーザーが消えているか |

以下の質問に回答してください。

1. 手順2で登録したユーザーの名前・メール・ロールは何ですか？
2. 手順4で何を変更しましたか？変更前と変更後の値を記載してください。
3. 手順5の後、pgAdminで該当ユーザーの `deleted` カラムの値を確認してください。値は何ですか？

### 解答

1. 回答例：名前「テスト太郎」、メール「test@example.com」、ロール「user」（受講者が入力した内容）
2. 回答例：名前を「テスト太郎」→「テスト次郎」に変更、ロールを「user」→「admin」に変更
3. `deleted` カラムの値は **`true`**（論理削除のため、レコード自体はDBに残っている）

## 課題2：コード品質チェック

### 課題設問

VSCodeのソース管理タブで全ファイルの差分を確認し、以下のチェック項目に回答してください。

1. 不要な `console.log` が残っている箇所はありましたか？（ある場合はファイル名を記載）
2. コメントアウトした不要コードが残っている箇所はありましたか？
3. 未使用の `import` 文が残っている箇所はありましたか？
4. 全て修正した後、コミットメッセージは何にしましたか？

### 解答

1. 回答例：「`UserList.tsx` に `console.log('users:', users)` が残っていたので削除した」（問題がなければ「なし」）
2. 回答例：「`EditUserForm.tsx` にコメントアウト済みの古い処理が残っていたので削除した」
3. 回答例：「`UserCard.tsx` に使用されていない `import Link` が残っていたので削除した」
4. 回答例：
   ```bash
   git commit -m "一覧・削除・詳細機能の実装完了・コード整理済み"
   ```
