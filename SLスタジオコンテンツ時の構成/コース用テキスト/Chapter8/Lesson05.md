# Lesson05：【実践課題】機能の結合と動作テスト・整理

## 課題の概要

Chapter7〜8で実装した全機能（新規登録・編集・一覧・詳細・削除）を統合し、**一連の操作が正常に動作することをテスト**してください。

---

## 統合テスト手順

以下の操作を順番に実施し、全て正常に動作することを確認してください。

1. **一覧表示**：ユーザー一覧が表示されること
2. **新規登録**：新しいユーザーを登録し、一覧に追加されること
3. **詳細表示**：ユーザーの詳細画面で情報が正しく表示されること
4. **編集**：ユーザー情報を変更し、反映されること
5. **削除**：ユーザーを削除し、一覧から消えること

---

## 差分確認と整理

### 1. ソース管理タブで差分確認

- 不要な `console.log` の除去
- コメントアウトされた不要コードの削除
- 未使用 `import` の削除
- インデントの統一

### 2. コミットとプッシュ

```bash
git add .
git commit -m "一覧・削除・詳細機能の実装完了"
git push origin develop
```
