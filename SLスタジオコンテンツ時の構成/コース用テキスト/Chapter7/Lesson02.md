## 段取りの作成方法

以下の要素を整理してからタスクに着手してください。

### 確認事項の洗い出し

- 既存のAPI通信処理はどこに記述されているか？（`utils/api.ts` を確認）
- ユーザー情報のインターフェース定義は？
- `fetch` を使わない通信処理とは？（プロジェクト内の既存コードを参考にする）
- ページ遷移の方法は？（`useRouter` を使用）

### タスクリストの例

```markdown
【概要】
タスク1-1：新規登録画面コンポーネントの作成

【タスクの詳細】
・対象ファイルの作成
　　作成場所：components/
　　ファイル名：RegisterForm.tsx
・インターフェースの定義
　　名前：RegisterFormProps
　　プロパティは資料を参照
・外部からデータを受け取れるようにPropsを設定
・新規登録の処理を実装
・登録用のフォームを実装
　　項目：名前、メール、ロール
　　登録ボタンに onClick を追加し新規登録処理を呼び出す
　　登録後にユーザー一覧画面に遷移するように設定

【確認事項】
・新規登録の方法を確認する（fetchとどう異なるのか？）
・画面の遷移方法を確認する
・RegisterFormPropsの役割を確認する
```

## ヒント

### Propsの設計

登録成功時のページ遷移を関数としてPropsから受け取る方法があります。

```tsx
interface RegisterFormProps {
  onSuccess?: () => void;
  onError?: (error: any) => void;
  disabled?: boolean;
}
```

こうすることで、Storybookでは `onSuccess` に `alert()` を設定し、実際のページでは `router.push('/users')` を設定できます。
