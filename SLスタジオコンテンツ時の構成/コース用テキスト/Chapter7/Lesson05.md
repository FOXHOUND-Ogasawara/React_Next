# Lesson05：【実践課題】編集（Update）機能の実装と整理

## 課題の概要

新規登録機能と同じ流れで、**ユーザー編集機能**を自力で実装してください。

Lesson02の段取りとLesson03〜04の実装パターンを参考に進めましょう。

---

## 実装タスク

### タスク2-1：EditUserFormコンポーネントの作成

- 対象ファイル：`components/EditUserForm.tsx`
- 仕様
  - `EditUserFormProps` インターフェースを定義
  - ユーザーの編集機能（名前・メール・ロール）
  - 「更新」ボタンでデータ更新
  - 更新成功後は `onSuccess` を呼び出す

### タスク2-2：EditUserFormのストーリー作成

- 対象ファイル：`components/EditUserForm.stories.tsx`
- 仕様
  - デフォルトストーリーに `userId` が「1」のユーザーを設定
  - Storybookで表示・操作が確認できること

### タスク2-3：ユーザー編集ページの修正

- 対象ファイル：`app/users/[id]/edit/page.tsx`
- 仕様
  - `EditUserForm` を使って編集画面を表示
  - 対象ユーザーの情報がフォームのデフォルト値として設定
  - 更新成功後にユーザー一覧画面に遷移

---

## チェックポイント

- [ ] EditUserFormコンポーネントが作成されている
- [ ] Storybookでフォームの表示・操作が確認できる
- [ ] 編集ページにアクセスすると対象ユーザーの情報が初期表示される
- [ ] 情報を変更して「更新」すると反映される
- [ ] 更新後にユーザー一覧画面に遷移する

## 差分確認と整理

実装完了後、以下の手順でコードを整理してください。

1. VSCodeのソース管理タブで差分を確認
2. 不要な `console.log` やコメントアウトを削除
3. コミットしてプッシュ

```bash
git add .
git commit -m "ユーザー編集機能の実装完了"
git push origin develop
```
