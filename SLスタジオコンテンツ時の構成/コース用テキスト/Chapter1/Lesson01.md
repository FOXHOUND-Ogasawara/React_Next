# Lesson01：コースガイダンスと開発の段取り

## はじめに

本コースは、これまでに学んだ **HTML/CSS・React・PostgreSQL・Git** の知識を統合し、実務レベルのWebアプリケーションを開発するためのステップアップコースです。

これまでの4つの基礎コースでは、それぞれの技術を個別に学んできました。しかし、実際のプロジェクトではこれらの技術は **組み合わせて使う** ことが前提です。

- ReactからAPIを叩いたことがない
- フロントエンドとデータベースを繋いだ経験がない
- 既存プロジェクトのコードを読み解けない
- Next.jsやStorybookなど実務ツールを触ったことがない

本コースでは、これらの「最後のギャップ」を埋め、**コース修了後にNext.jsとReactを理解し、自分でAPIを作り、DBと連携してCRUD処理を実装し、Gitでプッシュできる状態**を目指します。

## 「開発の段取り」とは何か

実務でタスクを受け取った際に、いきなりコードを書き始めるのは望ましくありません。

**タスクを受け取ってからコードを書き始めるまでに、やるべきことがあります。**

### 段取りの基本ステップ

1. **タスクの内容を確認する**
   - 何を作るのか？何が求められているのか？
   - 設計書や要件定義書を読み解く

2. **実装順序を整理する**
   - どのファイルを作成・修正するのか？
   - どの順番で実装すれば効率的か？
   - 不明点や確認事項を洗い出す

3. **実装する**
   - 整理した内容に沿ってコードを書く

4. **動作確認する**
   - 実装した内容が正しく動くか確認する
   - Chrome DevToolsなどを活用してデバッグする

5. **実装結果を整理する**
   - 何をしたか、何が変わったかを技術的に整理する
   - 不要なコード（console.log等）が残っていないか確認する

### タスクリストの例

以下は「ユーザー情報の一覧機能を実装する」場合のタスクリスト例です。

```markdown
【概要】
ユーザー情報の一覧機能を実装する

【タスクの詳細】
・対象ファイルの確認
　　components/UserList.tsx を作成
・fetchを利用したデータ取得処理を実装
・mapを利用してユーザー情報を一覧表示する
　　・id, name, age を表示する
・App.tsxにルーティングを追記する
・動作確認

【確認事項】
・出力するユーザー情報はid, name, ageで問題ないか
・画面構成に指定はあるか
```

このように、**実装前にタスクを分解して整理する**ことで、作業の漏れを防ぎ効率的に進めることができます。

## 「実装後の整理」と差分確認の重要性

コードを書き終えたら、それで終わりではありません。

実務では、実装した内容を他のメンバーに共有したり、レビューを依頼したりします。その前に、**自分で変更内容を確認する習慣**をつけておくことが重要です。

### VSCode標準のソース管理タブ

本コースでは、Git入門コースで学んだCLI操作に加え、**VSCode標準のソース管理タブ**を活用して変更差分を確認する方法を学びます。

#### ソース管理タブの開き方

1. VSCodeの左側サイドバーにある **ソース管理アイコン**（分岐のマーク）をクリック
2. または `Ctrl + Shift + G` を押す

#### 差分を確認するポイント

- **変更したファイル一覧**が表示される
- ファイルをクリックすると **変更前（赤）と変更後（緑）** が並べて表示される
- 以下の観点でチェックする
  - 不要な `console.log` が残っていないか
  - コメントアウトしたコードが残っていないか
  - 意図しない変更が含まれていないか
  - インデントやフォーマットが崩れていないか

この「差分確認の習慣」は、実務でプルリクエスト（PR）を出す前の自己チェックとして必須のスキルです。

## 本コースの学習サイクル

本コースでは、Chapter3以降の実践的な内容で以下のサイクルを繰り返します。

```
┌─────────────┐
│  ① 段取り    │  タスクの確認 → 実装順序の整理
└──────┬──────┘
       ↓
┌─────────────┐
│  ② 実装      │  コーディング
└──────┬──────┘
       ↓
┌─────────────┐
│  ③ 動作確認  │  DevTools活用 → 正常動作の検証
└──────┬──────┘
       ↓
┌─────────────┐
│  ④ 整理      │  差分確認 → 不要コード除去 → コミット
└──────┬──────┘
       ↓
   次のタスクへ
```

このサイクルを意識しながら学習を進めてください。最初は意識的に行う必要がありますが、繰り返すことで自然と身につくようになります。
