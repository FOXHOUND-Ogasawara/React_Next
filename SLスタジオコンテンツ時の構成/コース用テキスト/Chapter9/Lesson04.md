# Lesson04：【実践課題】最終デバッグ・不要コードの完全除去

## 課題の概要

ユーザー管理システムの全実装が完了しました。最終提出前に、**コード品質の最終チェック**を行います。

---

## 課題1：全機能の最終テスト

### 課題設問

以下のテスト項目を実施し、各項目の結果（OK / NG）を記録してください。NGの場合は原因と修正内容も記載してください。

| # | テスト項目 | 操作 | 期待結果 | 結果 |
|---|---|---|---|---|
| 1 | 一覧表示 | `/users` にアクセス | ユーザー一覧がカード形式で表示される | _____ |
| 2 | 新規登録 | 名前・メール・ロールを入力して登録 | 一覧に新ユーザーが追加される | _____ |
| 3 | 詳細表示 | カードの「詳細」ボタンをクリック | 詳細画面に正しい情報が表示される | _____ |
| 4 | 編集 | ユーザー情報を変更して更新 | 一覧で変更が反映される | _____ |
| 5 | 削除 | 「削除」→ モーダル確認 → 実行 | 一覧からユーザーが消える | _____ |

### 解答

全項目で「OK」となることが期待される。NGの場合の修正例：

- テスト2がNG → `RegisterForm` の `onSuccess` で `router.push('/users')` が正しく設定されているか確認
- テスト5がNG → `softDeleteUser` APIが正しく呼ばれているか、stateの `filter` 処理が正しいか確認

## 課題2：コード品質の最終チェック

### 課題設問

VSCodeのソース管理タブで全ファイルの差分を確認し、以下のチェック項目のそれぞれについて結果を記録してください。

1. 不要な `console.log` が残っていないか
2. コメントアウトした不要なコードが残っていないか
3. 未使用の `import` 文が残っていないか
4. 未使用のコンポーネント・関数が残っていないか
5. インデントが統一されているか（2スペース or 4スペース）
6. TypeScriptの型定義が `any` で放置されていないか

### 解答

全項目で「問題なし」が望ましい。問題があった場合の修正例：

1. `console.log` → 削除する（`console.error` によるエラーログは残してよい）
2. コメントアウト → 不要な場合は行ごと削除する
3. 未使用import → 行を削除する
4. 未使用のコンポーネント → `DeleteUserButton.tsx` が `CustomButton` に置き換わった後も残っている場合はファイルごと削除
5. インデントの統一 → VSCodeの設定でエディター全体のインデントを統一する
6. `any` 型 → 具体的な型に置き換える（例：`(error: any)` → `(error: Error)`）
