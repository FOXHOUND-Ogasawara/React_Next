# Lesson04：【実践課題】最終デバッグ・不要コードの完全除去

## 課題の概要

ユーザー管理システムの全実装が完了しました。最終提出前に、**コード品質の最終チェック**を行います。

---

## 課題1：全機能の最終テスト

以下の操作テストを実施し、全て正常に動作することを確認してください。

| テスト項目 | 操作 | 期待結果 |
|---|---|---|
| 一覧表示 | `/users` にアクセス | ユーザー一覧がカード形式で表示される |
| 新規登録 | 名前・メール・ロールを入力して登録 | 一覧に新ユーザーが追加される |
| 詳細表示 | カードの「詳細」ボタンをクリック | 詳細画面に正しい情報が表示される |
| 編集 | ユーザー情報を変更して更新 | 一覧で変更が反映される |
| 削除 | 「削除」ボタン → モーダル確認 → 実行 | 一覧からユーザーが消える |

---

## 課題2：コード品質チェック

VSCodeのソース管理タブで全ファイルの差分を確認し、以下の観点でチェックしてください。

### チェックリスト

- [ ] 不要な `console.log` が残っていない
- [ ] コメントアウトした不要なコードが残っていない
- [ ] 未使用の `import` 文が残っていない
- [ ] 未使用のコンポーネント・関数が残っていない
- [ ] インデントが統一されている
- [ ] TypeScriptの型定義が適切に行われている

---

## 課題3：Storybookの一括確認

`npm run storybook` を起動し、全コンポーネントのストーリーが正しく表示されることを確認してください。

- [ ] RegisterForm のストーリーが表示される
- [ ] EditUserForm のストーリーが表示される
- [ ] UserList のストーリーが表示される
- [ ] UserDetails のストーリーが表示される
- [ ] DeleteUserButton のストーリーが表示される
- [ ] CustomButton の全バリエーションが表示される
- [ ] CustomCard のストーリーが表示される
- [ ] CustomModal のストーリーが表示される

---

## 課題4：最終コミット

全てのチェックが完了したら、最終コミットを行ってください。

```bash
git add .
git commit -m "ユーザー管理システムの実装完了・最終整理済み"
git push origin develop

# developをmainにマージ
git checkout main
git merge develop
git push origin main
```
