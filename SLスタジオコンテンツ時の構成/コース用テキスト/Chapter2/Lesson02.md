# Lesson02：【課題】Thunder ClientによるAPI疎通確認

## 課題の概要

前のLessonで学んだWeb APIの知識を使って、**Thunder Client** を利用しAPIの疎通確認を行います。

Thunder Clientは、VSCode上で直接APIリクエストを送信できる拡張機能です。プログラムを書かずにリクエストとレスポンスを確認できるため、**APIの動作確認（疎通確認）**に非常に便利です。

### Thunder Client のインストール

1. VSCodeを開く
2. 左側の拡張機能アイコン（四角のマーク）をクリック
3. 検索バーに「Thunder Client」と入力
4. 「Thunder Client」をインストール
5. インストール後、左側サイドバーに雷マークのアイコンが表示される

### Thunder Client の基本操作

1. 左側サイドバーの **雷マーク** をクリック
2. 「New Request」をクリック
3. 以下を設定してリクエストを送信する
   - **HTTPメソッド**：GET / POST などを選択
   - **URL**：リクエスト先のURLを入力
   - **Headers**：必要なヘッダー情報を設定
   - **Body**：POSTの場合にリクエストデータを設定
4. 「Send」ボタンをクリック
5. 右側の **Response** エリアにレスポンスが表示される

## 課題1：The Cat API からデータを取得しよう

### 課題設問

Thunder Clientで「New Request」を作成し、以下の設定でリクエストを送信してください。

| 項目 | 設定値 |
|---|---|
| HTTPメソッド | `GET` |
| URL | `https://api.thecatapi.com/v1/images/search` |

リクエスト送信後、以下の質問に回答してください。

1. ステータスコードは何ですか？
2. レスポンスのJSON構造はどうなっていますか？（キーの一覧を列挙してください）
3. 画像のURLはどのキーに格納されていますか？

### 解答

1. ステータスコードは **`200 OK`**
2. レスポンスは配列形式で、各要素に以下のキーが含まれている
   ```json
   [
     {
       "id": "xxx",
       "url": "https://cdn2.thecatapi.com/images/xxx.jpg",
       "width": 1024,
       "height": 768
     }
   ]
   ```
3. 画像のURLは **`url`** キーに格納されている（配列の各要素の `url` プロパティ）

## 課題2：OpenWeatherMap API から天気情報を取得しよう

### 課題設問

Thunder Clientで「New Request」を作成し、以下の設定でリクエストを送信してください。

| 項目 | 設定値 |
|---|---|
| HTTPメソッド | `GET` |
| URL | `https://api.openweathermap.org/data/2.5/weather?q=Tokyo&units=metric&lang=ja&appid=YOUR_API_KEY` |

> **注意：** `YOUR_API_KEY` の部分を、Lesson01で取得した自分のAPIキーに置き換えてください。

リクエスト送信後、以下の質問に回答してください。

1. ステータスコードは何ですか？
2. レスポンスJSON内で、**天気の説明文**はどのキーに格納されていますか？
3. レスポンスJSON内で、**気温（temperature）** はどのキーに格納されていますか？
4. レスポンスJSON内で、**天気アイコンのコード** はどのキーに格納されていますか？
5. クエリパラメータの `units=metric` を削除して再度リクエストした場合、気温の値はどう変わりますか？その理由は何ですか？

### 解答

1. ステータスコードは **`200 OK`**
2. 天気の説明文は **`weather[0].description`** に格納されている（例：「晴天」「曇りがち」）
3. 気温は **`main.temp`** に格納されている（例：`25.3`）
4. 天気アイコンのコードは **`weather[0].icon`** に格納されている（例：`"01d"`）
5. `units=metric` を削除すると、気温がケルビン（K）で表示される。`units=metric` は摂氏（℃）で返すように指定するパラメータであり、デフォルトはケルビンのため。

## 課題3：別の都市の天気を取得してみよう

### 課題設問

クエリパラメータの `q=Tokyo` を別の都市名に変更して、天気情報を取得してください。

- 例：`q=Osaka`、`q=London`、`q=NewYork`

以下の質問に回答してください。

1. 選んだ都市名と、その都市の**現在の気温**を回答してください。
2. 存在しない都市名（例：`q=XXXXXX`）を指定した場合、**ステータスコード**は何になりますか？

### 解答

1. 回答例：都市名「Osaka」、気温「22.5℃」（※実行時の天候により異なる）
2. 存在しない都市名を指定した場合、ステータスコードは **`404 Not Found`** になる。レスポンスには `{"cod":"404","message":"city not found"}` が返される。

## 課題4（発展課題・任意）：APIキーをHeaderに設定してリクエストする

### 課題設問

APIキーをHeaderに設定してThe Cat APIを叩いてみましょう。

| 項目 | 設定値 |
|---|---|
| HTTPメソッド | `GET` |
| URL | `https://api.thecatapi.com/v1/images/search?limit=5` |
| Header | `x-api-key: YOUR_CAT_API_KEY` |

1. レスポンスには何件のデータが返ってきましたか？
2. APIキーをHeaderに設定する場合と、クエリパラメータに含める場合の違いは何ですか？

### 解答

1. `limit=5` を指定しているため、**5件** の猫画像データが返ってくる。
2. **Headerに設定する場合**はURLに含まれないためブラウザの履歴やログにAPIキーが残りにくく、セキュリティ的に安全。**クエリパラメータの場合**はURLに含まれるため、ログやブックマーク等に残りやすい。
